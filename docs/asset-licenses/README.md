维护规则：
- 新增外来素材（图/视频/字体）必须先建 `<id>.md`：来源 URL、授权条款原文/截图路径、
  下载时间戳、核对人；CC-by 及以上署名义务素材禁入 V1（无处署名），V2 若 CC-by
  署名字面交产品放内页页脚致谢位（06 册 §2）。
- 自产素材档案含：生成器文件路径、随机种子、复跑命令、产物 sha256、验收指标实测值。
- 素材文件本体放 `src/assets/media/`（视频）或对应资源目录，本目录只放证据文档。
