# V1 · 字内信号/信号星云（8s 无缝循环）— 自产证据档案

- 用途：03 册大标题 mask 字内信号 + 01 册圆形窗（F2/F3 接线；本批仅产制与验收）
- 归属：自产（本站所有，无外部授权项）；生成方式=本站代码 canvas 逐帧渲染 + ffmpeg 编码
- 规格：1920×1080 · 30fps · 240 帧 · 无音轨 · VP9 webm（CRF31）+ H.264 mp4（CRF31, faststart, yuv420p）
- 验收口径来源：shared/phase3-design-final-v2/06-f4-video-brief.md §1/§3

## 生产管线（可复跑）
| 环节 | 路径 | 说明 |

## 循环无缝构造性保证 + 实测
- 设计：所有运动相位均为 loop 周期函数——粒子/数据线位置 `(u + p·sp) mod 1`（sp 整数），
  灯丝交织/星闪/信标脉冲/星云呼吸均 `sin(2π·p·f + φ)`（f 整数），颗粒噪点为静态图层。
  故 phase=1.0 帧与 phase=0 帧按构造恒等。
- 实测（`f4_analyze.py diff`，纯 stdlib PNG 解码逐像素）：
  首帧 vs 补帧（phase=1.0）mean_abs_diff = **0.0000/255**（验收线 ≤3/255，构造性恒等复验通过）。
