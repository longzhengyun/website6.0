# V2 · 夜海星光数据带（6s 无缝循环）— 自产证据档案

- 用途：01 册 L2 液滴长窗环境带（星辰大海元素在 L2 的唯一呼吸位）
- 归属：自产（本站所有，无外部授权项）；生成方式=本站代码 canvas 逐帧渲染 + ffmpeg 编码
- 规格：1280×720（背景层分辨率下探，asset-manifest 已定）· 30fps · 180 帧 · 无音轨 ·
  VP9 webm（CRF31）+ H.264 mp4（CRF31, faststart, yuv420p），目标 ≤6MB
- 验收口径来源：shared/phase3-design-final-v2/06-f4-video-brief.md §2/§3

## 生产管线（可复跑）
| 环节 | 路径 | 说明 |
|---|---|---|
| 渲染器（工程文件） | `.qa-scratch/phase3-f4/v2-renderer.html` | 纯 canvas 2D；确定性 PRNG `mulberry32(0x5EA2)` |

## 循环无缝构造性保证 + 实测
- 设计：横向漂移/数据线 `(u + p·sp) mod 1`（sp 整数）、星闪与波光 `sin(2π·p·f)`（f 整数）、
  颗粒静态图层 → phase=1.0 与 phase=0 恒等。
- 实测：首帧 vs 补帧 mean_abs_diff = **0.0174/255**（验收线 ≤3/255）。

## 色彩口径（06 册 §2 验收色域）
- 主色带限定 `#0b0e13–#101826–#0e1a20` 至青 `#37d0c0` 区间（星空冷白除外为蓝相）；
  天光暖色 0（帧统计 warm 占比见实测记录）；纹理亮度按 §3 底域压至 ≤15% 均值，
  叠 12% 黑遮罩后仍可辨=合格判据交设计确认。
