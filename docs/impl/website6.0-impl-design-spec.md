## 1. 全局设计原则

1. **移动优先**：所有尺寸以 375px 为设计基线，桌面为增强；每个 spec 区块先定义移动端，再给 ≥768px 覆写。
2. **排版即视觉**：不依赖装饰性图形，层级由字号对比、留白、编号系统建立。
3. **双模式跟随系统**：`prefers-color-scheme` 驱动，无强制手动切换器（P2 可加）；所有 token 双值成对定义。
4. **原生 CSS 优先**：动效全部 CSS 实现（scroll-driven animations + View Transitions），JS 仅用于 ⌘K 面板与 theme 跟随监测。
5. **A11y 是底线不是特性**：对比度 AA（正文 ≥4.5:1，大字号 ≥3:1）、焦点环可见、触控目标 ≥44×44px、`prefers-reduced-motion` 全站降级。

## 2. Token 表

命名建议：Tailwind 4 CSS-first `@theme` 变量（下列名即建议 var 名，前端可加 `--color-`/`--font-` 前缀规范微调）。

### 2.1 色彩（Oklch 或 Hex 均可，值以对比度实测为准）

| Token | 亮色模式 | 暗色模式 | 用途 | 对比度备注 |
|---|---|---|---|---|
| `bg` | `#FAFAF8` 纸白 | `#0B0D11` | 页面底色 | — |
| `surface` | `#FFFFFF` | `#14171D` | 卡片/新闻条目底 | 与 bg 靠 1px 线而非阴影区分 |
| `ink` | `#14161A` | `#F2F3F0` | 正文主色 | 对 bg ≥13:1 |
| `ink-muted` | `#5A5E66` | `#9BA3AF` | 简介/meta/摘要 | 对 bg ≥4.6:1（AA 达标线，前端复测） |
| `ink-faint` | ~~`#8B9098`~~ → `#6A6E76`（v1.1 §9） | ~~`#5F6773`~~ → `#7B8394`（v1.1 §9） | 编号、分隔线文字、弱化链接 | 原值不达 AA（实测 3.07–3.4:1），v1.1 起加深；用途边界见 §9 |
| `line` | `#E3E2DE` | `#262B33` | 1px 栅格分隔线 | — |
| `accent` | `#E5484D` 朱红 | `#5EEAD4` 磷光青 | 大字/图形/按钮底/**非文字指示**（下划线/边框/书脊，v1.1 §9） | 暗底磷光青对 bg ≥10:1；亮底朱红对小字 3.74–3.91:1 不达 AA——**任何 <18px 文字（含 nav/tab/chip 激活态小字）禁用 accent 作文字色**，改中性字色 + accent 非文字指示（见 §9） |
| `accent-ink` | `#FFFFFF`（在 accent 底上） | `#0B0D11`（在磷光青底上） | 强调按钮文字 | 按钮文字对比 ≥4.5:1 |
| `focus-ring` | = accent | = accent | `outline: 2px solid`，offset 2px | 焦点必须双通道（颜色+轮廓） |

规则：accent 每屏出现 ≤3 处；新闻列表默认全中性色，accent 只标记交互态与筛选选中项。

### 2.2 字体与字号阶梯

- 英文/数字展示：可变字体（建议 Geist Variable，备选 Inter Variable），`font-variation-settings` 参与动画。
- 中文正文：系统中文栈 `"PingFang SC", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif`（不引入 webfont 中文全量，LCP 红线）。
- 等宽（编号/meta/终端元素）：Geist Mono / JetBrains Mono，仅拉丁字符，体积极小可自托管 woff2 subset。

**字号阶梯（rem，1rem=16px；M=移动 375 基线 / D=≥768）**

| Token | M | D | 行高 | 字重(wght)/ optical | 用途 |
|---|---|---|---|---|---|
| `text-display` | 3.0rem (48px) | 6.5rem (104px) | 1.02 | 620→400 呼吸插值 | 首页站名 |
| `text-h1` | 2.0rem | 2.75rem | 1.15 | 600 | 页标题（News/About） |
| `text-h2` | 1.375rem | 1.5rem | 1.25 | 560 | 区块标题、新闻条目标题 |
| `text-h3` | 1.125rem | 1.25rem | 1.3 | 540 | 次级标题 |
| `text-body` | 1rem | 1.0625rem | 1.65 | 400 | 正文/简介 |
| `text-small` | 0.875rem | 0.9375rem | 1.5 | 440 | meta、日期、标签 |
| `text-label` (mono) | 0.75rem | 0.8125rem | 1.4 | 500，字距 +0.08em | 编号 `01/`、`§`、导航序号 |

中文排版注意：中文标题字重上限 600（系统字体过粗会糊），行高比英文 +0.05；`text-display` 中文场景禁用可变动画（无 VF 支撑），改用静态粗体。

### 2.3 间距 / 圆角 / 其他

| Token | 值 | 用途 |
|---|---|---|
| `space-1..8` | 4/8/12/16/24/32/48/64px | 栅格间距一律取 space 值，禁魔法数 |
| 区块纵向节奏 | M: `space-7`(48px)；D: `space-8`(64px)×1.5 节间 | 页面大区块间隔 |

| z-index 阶梯 | nav 40 / ⌘K 层 50 / toast 60 | 前端沿用即可 |

### 2.4 栅格与版心

| 视口 | 版心 max-width | 栅格 | 页边距 |

## 3. 站名视觉方案（「佳瑞网 / jary8」定稿落地）

**推荐方案 L1「双语叠印」**：

```
jary8·佳瑞网          ← display 层（桌面）
──────────
Web 前端工程师，做最前沿的界面   ← 身份一句话（产品文案候选另行）
```

- 桌面：第一行 `jary8` 用可变字体 display（小写，字距 -0.03em，呼吸动画只作用在 jary8 上），中点 `·` 用 accent 色，紧跟「佳瑞网」同字号静态粗体中文——英文承担动效、中文承担识别，正好解决 Q4 语言问题。
- 移动：两行制。上行 `佳瑞网` 2.25rem 静态；下行 `jary8` mono 体 0.875rem + accent 下划线装饰（像域名而非单词），display 呼吸效果在移动端降级为透明度 0.96↔1 微幅——省电且不粗糙。
- 页头/导航缩写：`jary8` mono 小写，导航左侧固定；favicon 建议 `j8` 直角黑底反白。
- 备选 L2「纯终端」：`~/jary8 $ 佳瑞网`（提示符风，A 方向更重，差异化弱，不推荐主用，可用在 404/加载态）。
- 待产品文案候选到位后，仅替换身份一句话文本，版式不变。

## 4. 逐页 Spec

### 4.1 首页 `/`（P0）

**结构（自上而下）**：顶栏（左 `jary8` 缩写标 + 右 `News / About` 两项）→ Hero（站名 display + 身份一句话 + 单一视觉焦点=字体呼吸）→ 最新 3 条新闻预览（编号+标题+简介，整卡直跳）→ 页脚（`简历` 暗线入口 + 版权 + 邮箱）。

- Hero 占屏：M 端 60vh 最小；D 端垂直居中、上方留白 24vh。除站名与一句话外不放任何按钮/图形。
- 新闻预览条目：`01/` mono 编号 + h2 标题 + 一行截断简介（`-webkit-line-clamp:2`）；右箭头 `→` 提示外链；整卡 `<a>`，新窗口 `rel="noopener"`。
- 主导航**无「简历」字样**（验收红线）；页脚简历入口用 `ink-muted`，hover/focus 转 accent。
- ⌘K 提示：D 端页脚一行 mono `按 ⌘K 直达任意内容`；M 端替换为底部固定小按钮 `⌘K`（44px 触控）。

### 4.2 News `/news`（P0）

**结构**：h1 `业内新闻` + mono 编号 `§02` → 顶栏筛选标签行（AI 标签，横向滚动，胶囊 0 圆角描边）→ 倒序列表 → 底部「数据来源 RSS · 构建期更新」mono 说明 + 上次构建时间（管线注入）。

- 条目：M 单列全宽；D 每条目 `0.75 版心 | 0.25 meta`双列（左标题+简介，右日期+标签竖排 mono）。
- 每条只显示：标题（h2）、简介（body，最多 2 行）、日期/来源（small）、外链箭头。无图、无阅读更多——硬约束。
- 筛选态：选中胶囊 accent 描边 + accent 文字；未选 `ink-muted` 描边。键盘可达（Tab 到每个胶囊，Enter 切换）。
- 列表入场：scroll-driven 逐条 reveal（见 §5）。

### 4.3 About `/about`（P0）

**结构**：h1 + mono `§03` → 自述段（版心 6/12 col，行长 ≤34 汉字）→ 技能栈矩阵 → 履历时间线 → 简历内链区。

- 技能栈：网格卡片 0 圆角 + 1px 线，M 2 col / D 4 col；每卡 = 名称 + mono 年限/等级条（等级用 5 格实心方块 `■■■■□` 终端字符风，不用百分比数字）。
- 时间线：M 端垂直单列左侧 mono 年份 + 细竖线；D 端年份进入左侧 3 col 栏。
- 简历内链区：一行文字「需要 PDF？→ 在线简历」，`ink-muted` 常态，hover accent；这是简历第二暗线。
- 「问站长」（P1，落点③）预留位：时间线下方一个 mono 提示行容器 `> ask jary8 --about`，样式按输入行画，未启用时渲染为静态装饰并标注实验位。

### 4.4 Resume `/resume`（P0，弱化页）

- 无顶部主导航进入路径（页面自身顶栏只保留返回 `← jary8`）。
- 打印优先设计：`@media print` 下强制白底黑字、隐藏导航/页脚/动效、A4 分页避免段落截断（`break-inside: avoid`）——打印导出 PDF 即验收项（Q7）。
- M 端：区块手风琴默认展开（打印与阅读一致，不做折叠以免误伤 ATS 复制）。
- 屏幕版式：单列 ≤680px 宽、`space-4` 段距、标题 h2、正文 body；日期一律 mono 右对齐（D 端）。

### 4.5 404（P2，简述）

终端风：`404 — page not found` mono 输出块 + 一行冷幽默 + `cd /`（回首页链接）。尺寸沿用 token，不新增样式。

## 5. 动效时序表（全部 CSS 实现）

| # | 名称 | 触发 | 属性与时序 | reduced-motion 降级 |
|---|---|---|---|---|
| A1 | 站名呼吸 | 常驻（仅 `jary8` 拉丁 display） | `font-variation-settings: wght 400↔640, opsz 随值联动`；14s `ease-in-out` 无限往复，`prefers-reduced-motion` 停在中值 500 | 静止 wght 500 |
| A2 | 条目入场 | 滚动，`animation-timeline: view()` | 区间 `cover 0% → cover 35%`；**仅 `translateY 12px→0`，opacity 恒为 1（v1.1 §8.6 修订：滚动绑定区间内 opacity 静止位必然产生低对比悬停态）**；250ms 等效速率；相邻条目因 view 区间自然错峰，不写 stagger JS | 直接可见（animation none） |
| A3 | 页面转场 | View Transitions（Astro 内置） | 根交叉淡入 200ms `cubic-bezier(0.33,1,0.68,1)`；滚动即时重置 | 同帧替换 |
| A4 | hover/focus | 指针与键盘 | 颜色/描边过渡 120ms；位移类（如箭头 `→` 右移 2px）160ms | 仅颜色变化，无位移 |
| A5 | ⌘K 面板 | 按键/点击 | 遮罩 `ink/40%` 淡入 120ms；面板自顶下沉 8px+淡入 180ms `cubic-bezier(0.16,1,0.3,1)`；焦点入输入框 | 无动画直接呈现，焦点管理不变 |
| A6 | 滚动书脊（D 端） | `animation-timeline: scroll(root)` | 右侧 2px accent 线 0→100% `scaleY`，实时；条目编号随视口中心切换为 accent（view() 驱动） | 隐藏书脊 |

性能红线：无 JS 逐帧动画；A1 仅 transform/font-variation（不触发布局重排的属性组合中 font-variation 有重绘成本，只在首页 hero 单元素使用，LCP 不受影响——字体加载完成前用 fallback 静态渲染）。

## 6. 移动端专项规范（一等验收，对应站主新要求）

### 6.1 触控目标
- 所有可点元素命中区 ≥44×44px（视觉可以小于命中区，用 padding/`::after` 扩展；新闻整卡天然达标）。
- 相邻可点元素间距 ≥8px（`space-2`）；筛选胶囊间 gap 12px。
- 列表项标题内不允许嵌套第二可点元素（一行一条链接，防误触）。

### 6.2 拇指区
- 高频操作（导航、⌘K、筛选、返回）置于视口下半部：M 端主导航折叠为底部常驻 tab 条（高 56px + `env(safe-area-inset-bottom)`，Home/News/About/⌘K 四项）而非顶部汉堡——单手可达。
- 低频（简历、邮箱、版权）留页脚正常流。
- 长列表滚动到顶行为不劫持，禁用任何需要拇指跨屏的拖拽手势。

### 6.3 折叠与导航
- 顶栏 M 端只保留左侧 `jary8` 标 + 底部 tab 条；不用抽屉。
- 筛选标签行 M 端 `overflow-x: auto` 单行横滚，隐藏滚动条，右侧 16px 渐隐遮罩提示可滚；不做「更多」折叠面板。

### 6.4 移动排版与输入
- hover-only 信息一律给 `:focus-visible`/active 等价态（移动无 hover，`@media (hover: none)` 下禁用依赖 hover 的提示文案）。
- 表单/输入（⌘K、BYOK 预留）：`autocomplete`、`enterkeyhint="search"`、聚焦时页面允许滚动到可视（`scroll-padding`）；字号 ≥16px 防 iOS 聚焦放大。
- 375px 下行长 ≤ 42 汉字；display 48px 时站名「佳瑞网」不折行（`text-wrap: balance`）。
- 图片/图标原则：MVP 页面除 favicon 与条目箭头（inline SVG 16px 视觉/44px 命中）外无位图——移动端流量与 CLS 双达标。

## 8. v1.1 增量：BUG-M4R-01 token 用色裁定（设计）

触发：测试 M4 复验（`E:\Jary\qa-outputs\website6.0\M4-reverify-20261023-01\evidence\`）+ 项目 seq=342 分派。范围**只裁颜色与用色策略**，实现归前端。所有 ratio 由 `node` 按 WCAG 相对亮度公式实测（脚本口径同 axe），非估算。

### 8.1 根因

1. **用色越界**：§2.1 原规定 `ink-faint`「仅用于非必读信息，正文禁用」，但实现把**必读元信息**挂到了 ink-faint（新闻日期/来源/#标签、`§02 / news` 面包屑、区段前缀 `01/ latest news`、导航序号 `02/ 03/`、以及 R16 副标题 `p.tagline-line` 身份句）。身份/日期/来源属必读，用装饰色本身即违规。
2. **装饰 token 值不达标**：即便降级为纯装饰，`ink-faint` 原值对比度也不够——实测 亮 `#8B9098` = 3.07:1(#FAFAF8)/3.21:1(#fff)，暗 `#5F6773` = 3.40:1(#0B0D11)/3.14:1(#14171D)，均 <4.5，axe 必判 serious。
3. **accent 小字违规**：§2.1 已写「正文级小字禁用朱红」，但 `nav a[aria-current]` 激活态（桌面 t-label 13px / 移动 tab-label 12px）用了 accent 文字色，实测 3.74/3.91:1 <4.5。

### 8.2 裁定（三项，前端照此实施）

**R-1 · ink-faint 双保险：用途降级 + 值加深**

- **必读元信息一律移出 ink-faint，改用 `ink-muted`**（§2.1：muted = meta/摘要；实测 亮 #5A5E66 = 6.23/6.51，暗 #9BA3AF = 7.64/7.05，两模式两底色全 ≥4.5）。具体改 `ink-muted` 的元素：新闻**日期、来源名、#标签**、`§02 / news` 文字部分、`01/ latest news` 里的**文字**部分、`p.tagline-line`（副标题身份句，属必读）、About/Resume 的小字 meta。
- **纯装饰序号/图形字符**（紧邻已有真标签、仅作视觉节奏的 `01/ 02/ 03/` 前缀数字、分隔线占位符、弱化/禁用态）保留 `ink-faint`，但**加深 token 值**为达 AA 的地板值，使其在装饰用途下也无需 aria-hidden 即通过：

  | Token | 亮色（旧→新） | 暗色（旧→新） | 新值实测（bg / surface） |
  |---|---|---|---|
  | `ink-faint` | `#8B9098` → **`#6A6E76`** | `#5F6773` → **`#7B8394`** | 亮 4.90:1 / 5.12:1；暗 5.11:1 / 4.71:1（两模式两底色全 ≥4.5） |

  加深后 `ink-faint`(#6A6E76) 与 `ink-muted`(#5A5E66) 层级差收窄；如需更强层次，前端可对装饰序号叠加 `letter-spacing`/更细字重或 `opacity:.85`（装饰件不受 AA 约束），或**可选**将 ink-muted 再深一档至 `#4A4E55`（6.9:1，进一步拉开，非必需）。**最小安全集**：只做上表两处 hex 变更即可让全部涉事节点（含装饰序号）过 axe。

**R-2 · accent 小字禁用 → 中性色 + 字重 + accent 非文字指示**

- 规则：**任何 <18px（非大号）文字一律不得用 accent 作文字色**，包括激活/当前态。
- 激活态（`nav a[aria-current="page"]`、选中 tab、选中 chip）改为：文字色 = `ink`（较非激活的 `ink-muted` 更深，形成层级对比）+ 字重 +50（400→500 / mono 500→600）+ **accent 非文字指示**（2px 下划线或左边框或实心小圆点）。指示条属非文字 UI 组件，适用 WCAG 1.4.11 的 3:1 阈值——朱红指示对底 3.74:1 ≥3 ✓，磷光青 13:1 ✓。
- 语义态仍以 `aria-current`/`aria-pressed` 为准（程序化状态，不依赖颜色），同时缓解 BUG-M4R-02 的「仅颜色区分」问题。
- 保留 accent 的合法用途：大字标题点缀、图形/进度书脊、按钮底（配 `accent-ink`）、focus-ring（颜色+轮廓双通道）。

**R-3 · 暗色 accent（磷光青）文字**：亮色禁用 accent 小字，暗色 `#5EEAD4` 对比 13:1 本身达 AA，可作为小字文字色使用；但为跨模式一致，激活态仍统一走 R-2 的「加深 + 字重 + 指示条」方案，磷光青留给指示条/边框/焦点环。

### 8.6 BUG-M4R-04 动效收敛裁定（v1.1，项目 seq=398 分派 / 前端 seq=400 可行性输入已核）

**结论：采方案③——入场带纯 transform，不动 opacity。§5 A2 行已同步修订。**

先认责：`.scroll-rise` 实现与 v1.0 spec A2 逐字一致（`opacity 0→1` 绑 `cover 0%→35%`），根因是**我原始裁定的缺陷**，非前端实施偏差——滚动时间线把动画进度绑在滚动位置，任何静止滚动位（尤其视口底缘带）都会把必读文本冻在中低 opacity 且不自愈。

三选一拍板理由：

- **③采纳**：translateY(12px→0) 保留 editorial 上升节奏与 view 区间错峰，opacity 全程恒 1 → 任意滚动静止位对比度即静态值，数学上根除该缺陷类；transform 不参与布局 → CLS=0（AC-R15-06 单屏约束安全）；reduce 直显（animation:none）与不支持浏览器 250ms 时间淡入回退均不动（时间动画 ≤250ms 自愈、非持久静止态，不构成 AA 违例）；news 逐卡结构不动。实现=仅在 @supports view() 块内把 animation-name 换 transform-only keyframes，纯 CSS 单点，静态探针/对比度全样本必过。代价（底缘带失去淡入、保留上移）由 A1 字体呼吸 + A6 滚动书脊补偿，「CSS 原生动效」技术身份无损。
- **②否决**（与前端反推一致）：合成色 ≥4.5:1 反推地板值——亮 ink-muted f≥0.93、ink f≥0.82，取证帧 0~0.27 需抬到近乎无衰减区间，淡入名存实亡；且每个 token×底色组合都要重推导，脆弱。
- **①否决**：IO+JS 违背本站零 JS 动效身份、需 enhanced-only 兜底与 ClientRouter 重跑语义、静止首帧仍短暂 <4.5（仅时间自愈），回归面约为③3 倍——对 12px 入场位移不成比例。

**观察项判定（seq=398-a / seq=400 附）**：pulse 区「全部新闻 →」被 `main a.arrow-link:not(.tab-item)` 命中——**是设计意图，维持，不收窄选择器**。它是动态条内唯一文字型 inline 链接，下划线正是 M4R-02 修复所求非颜色线索；两条题卡整体锚点无 arrow-link、标题 p.arrow-link 非 `<a>` 不命中——inline 链接与块卡的区分恰好正确。若后续走查认为动态条过密再议收窄，本轮不动。

**影响面**：global.css `@keyframes rise`/animation-name 一处；测试出口批 axe 四组合预期转绿（违例源消除，非新增豁免）；「·」圆点重心、::before 指示条 computed 两项出口走查挂账不变。批三同一叠推窗可并（seq=391 口径）。

### 8.8 BUG-M4R-05 裁定（v1.1.2，项目 seq=486 分派，设计直裁）

**结论：否决改值前提——BUG-M4R-05 是测试探针亮度函数的算术伪阳，非 token 违例。亮色 `--c-ink-faint` 维持 `#6A6E76`，不改值。**

裁定三要素（按 seq=486 期望输出）：
1. **亮色 ink-faint 终值**：`#6A6E76` 不变（标准 WCAG 口径 **#FAFAF8 底 4.90:1 / #fff 底 5.12:1**，两底均 ≥4.5 PASS）。
2. **波及选择器范围**：**无**（零改动；前端批六不成立，可取消）。
3. **spec 修订号**：升 **v1.1.2**，本节留档裁定与证据。

**决定性证据**（可复算，脚本口径=WCAG 2.1 标准式 L=0.2126R+0.7152G+0.0722B，lin(c)=((c+0.055)/1.055)^2.4；锚点自检 #767676@#fff=4.54 ✓）：

- 测试复现算式自曝误差源：其申报 fg L=**0.1814**，而 `lin(118)=0.1812`——118 正是 rgb(106,110,118) 的**蓝通道值**。即探针把相对亮度算成了仅蓝通道（或通道权重丢失），标准 L 应为 **0.1552**。
- 按申报值直接复现：(0.9584+0.05)/(0.1814+0.05)=**4.36** 与测试申报逐位一致 → 误差在分子源（fg L），非口径分歧。
- 此前 #8B9098 的「2.81」同为该伪口径产物（blue-only≈2.77；标准 3.07——两者都 FAIL，但数值对不上进一步坐实探针不稳定）。
- 测试「对 #fff 才是 ≈4.54」不成立：标准 #6a6e76@#fff=**5.12**；4.54 恰是 #767676@#fff 的业界锚值，系探针 artifact（1.05/(0.1814+0.05)）与该锚值的巧合撞数。
- 「resume 白底 4.54 临界过，token 面是否一并调整」的裁定输入本身是伪数值：**不调整**——白底实测 5.12，无临界问题。

**对测试的要求（M4R-05 转「探针修复待验」，不改 token）**：
1. 修复亮度函数（补全 R/G 通道权重）后按标准口径重跑 CT-* 全 16 组；预期 ink-faint 组转 4.90/5.12 PASS。
2. **暗面结果需同批复核**：blue-only 在深底上虚高 fg L → 违例**漏报**方向。设计已按标准口径代验：`#7B8394` = 5.11@#0B0D11 / 4.71@#14171D、ink-muted `#9BA3AF`@#14171D = 7.05，均 PASS——若探针修复后仍报违例，再开新号裁。
3. axe「背景归因失败 incomplete」与探针 bug 可能同源（computed 链解析），建议一并排查。

**兜底条款**：若探针修复后重测 #6a6e76 仍 <4.5（不预期；公式确定性的），采测试锚 `#666A72`（标准 5.19/5.43）。注意 #666A72 与 ink-muted #5A5E66 仅差 9 阶，ink 三级梯度视觉分层被压缩，触发时需设计复核层级后再放行。当前触发条件不成立，不采。

**流程影响**：批六取消后，第八笔（cf191f3，feat=ab8582d）放绿叠推不再有待改 token；M4R-01/M4R-05 待测试标准口径复验全绿后一并关闭。

**归因更正（v1.1.3，采测试 seq=505 复验轮审计证据）**：本节原判定「探针仅取蓝通道」**不成立**。实际根因是探针 lum() 幂项用 `((v+0.055)/1.055)^2.2` 近似替代 WCAG 2.1 规定的 `^2.4`——R/G/B 权重齐全；^2.2 下 #6a6e76 加权 L=0.1813 与 lin₂.₄(118)=0.1812 撞值（差 0.0001），致蓝通道单通道假设（设计 seq=493、项目 seq=497 归因）成为巧合误判。方向性结论不变：幂指数偏低抬高 fg L → 比值系统性偏低 → 假阳违例；深底 +0.05 占主导，原暗面 PASS 无假阴风险。本节全部数值结论（4.90/5.12/5.11/4.71/5.19 与维持 #6A6E76 的裁定）经测试修复版探针锚点自检 5/5 + CT2-* 全 16 组违例=0 复核成立，**裁定结果不受归因更正影响**。
