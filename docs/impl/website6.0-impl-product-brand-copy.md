# website6.0 品牌文案候选 — 首页身份一句话（产品侧）

作者：产品｜日期：2026-10-23
用途：首页仅两处文案——① 站点名（已定稿：英文主标题 JIARUI + 中文副题「佳瑞网」，域名 jary8.com）② 站长身份一句话（本文候选，供站主后续自选；站主未选前团队默认用 C1 推进，不阻塞 M2）
约束回顾：首页极简（站点名+身份，无营销模块）；首要访客=招聘方/技术同行（Q5）；移动优先，一句话在 375px 单行或两行内排下（建议 ≤20 个汉字或等效英文长度）

---

## 候选组 C1「工程师的克制」（默认推荐）
- 中文：Web 前端工程师。把浏览器能做的，做到最新。
- 英文对位：Front-end engineer. Shipping what the browser can do — the newest of it.
- 气质：编辑部风格、冷静自陈，与瑞士排版 B 方向最契合
- 风险：低调，情绪价值少；但招聘方视角可信度最高

## 候选组 C2「站点即作品」
- 中文：这个网站，就是我的简历。
- 英文对位：This site is my résumé.
- 气质：直击"设计体现站长技术"的要求，与"简历弱化不进导航"形成互文彩蛋——不放进导航，因为网站本身就是
- 风险：略口号化；若首页元素极简，这句话的信息量足够撑起焦点

## 候选组 C3「前沿+AI 双线」
- 中文：前端工程师 · 用最新的技术，和 AI 一起写网页。
- 英文对位：Front-end, newest stack, built with AI.
- 气质：把两大硬性要求（前沿技术、AI 结合）写进身份自陈，检索友好
- 风险：信息密度高、个性弱，偏"标签串"

## 使用建议
- 首页同时只出现一句；三组均按"中文主句 + 英文小字对位"双模式排版设计（跟随系统深浅色不影响）
- About 页首段可复用所选句的加长版（实施期由设计 spec 定）
- 站主自选项：C1 / C2 / C3 / 自拟——任何一组都不影响 IA 与验收条款（H1 只验证"站点名+身份表述存在且首屏极简"）
