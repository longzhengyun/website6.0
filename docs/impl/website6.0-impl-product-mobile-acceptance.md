# website6.0 移动端专项验收清单（M 系列）— 产品侧

作者：产品｜日期：2026-10-23
依据：站主裁定"站点需要支持移动端"（cmsg_01m5kgkshnd3dr3v4j7qxzymzz），移动体验为一等验收项
定位：补充 shared/website6.0-proposal-product.md §5 G2 之上，不削弱原条款；与 overview §2.6 一并供测试转成执行清单（M4 使用）
测试环境基准：375×667（小屏基线）+ 390×844 / 430×932（主流机）+ Chrome DevTools device emulation + 真机（iOS Safari、Android Chrome）至少各 1 台；网络 Fast 3G/4G 各跑一轮

---

## M-A 布局与排版（移动排版）

- M-A1 375px 宽度下所有 P0 页（/、/news、/about、/resume）无横向滚动、无内容溢出裁切
- M-A2 正文有效行长 ≤ 约 75 字符（移动端不出现通栏超宽文本）；字号移动端正文 ≥16px，不使用如需放大才可读的辅助文字
- M-A3 首页大字标题（佳瑞网/jary8）在 375px 下不折行破相、不溢出视口；可变字体呼吸动画在移动端降精度/暂停时内容仍完整可读
- M-A4 长表格/时间线（About 履历）在移动端有合理折叠或横向滚动方案，且横向滚动区可键盘/触摸操作
- M-A5 视口配置正确：允许用户缩放（不得 `user-scalable=no`），文本缩放 200% 不丢内容
- M-A6 图片/媒体按视口响应（srcset/sizes 或等效），移动端不加载桌面尺寸原图

## M-B 导航与触摸（折叠导航 + 触摸目标）

- M-B1 主导航在移动端为折叠形态（汉堡/底部栏/命令面板入口，具体由设计 spec 定），展开-选择-收起全流程 ≤3 步完成
- M-B2 全部可交互元素（链接、按钮、筛选标签、导航项）触摸目标 ≥44×44px，间距不小于 8px；相邻链接不粘连误触
- M-B3 拇指区：News 页筛选/翻页等高频操作位于下半屏可达区（对照设计 spec 的拇指区规范抽查）
- M-B4 新闻整条卡片为点击热区（不只标题小字可点），新窗口打开外链且 `rel="noopener"`；点击有可感知反馈（按压态），无 300ms 延迟类卡顿
- M-B5 简历暗线在移动端可达：页脚"Resume"链接为合格触摸目标；⌘K 不可用时（无实体键盘场景）不得成为唯一路径——页脚/About 内链必须保底存在
- M-B6 折叠导航展开时背景内容不可被误操作（焦点圈定在弹层内，Esc/点击外部/滑动可关闭）
- M-B7 浏览器前进/后退在移动 Web 上行为正常（View Transitions 不破坏返回手势/滚动位置恢复）

## M-C 性能与稳定性（移动一等）

- M-C1 Lighthouse 移动端 Perf ≥90、A11y ≥95、BP ≥95（Q14 门禁值，CI 同源复跑）
- M-C2 4G 模拟下首页 LCP <1.5s、CLS <0.05；首屏 JS ≤150KB（gzip 前口径以 CI 定义为准）
- M-C3 新闻管线降级模式在移动网络下不出现骨架屏长期停留；AI 标签筛选不可用时列表仍完整可用
- M-C4 无依赖 hover 才能发现的功能（移动端无 hover：所有 hover 态信息在常态或点击态可得）
- M-C5 深浅色双模式（跟随系统）在移动端系统切换时即时生效、无闪白/闪黑超 1 帧可感知异常

## M-D 无障碍（移动补充）

- M-D1 触摸目标验收同时通过 axe 无严重违规（移动视口跑一轮，不只桌面）
- M-D2 折叠导航对读屏可达：展开/收起状态有 ARIA 语义，Tab 顺序符合视觉顺序
- M-D3 对比度 AA 在移动端两主题（亮底朱红/暗底磷光青）下均达标（小字号辅助文本重点抽查）
