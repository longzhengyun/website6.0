## 2. 新增硬性需求：移动端一等验收（FR-M）

- 变更性质：**升级**。v1.0 中 G2（375/1440 无遮挡）是兼容底线；站主裁定后"支持移动端"为正式需求，移动体验是一等验收项。
- 范围含义：移动优先断点（375px 基线）；触摸目标 ≥44px、拇指区可达；导航在移动端折叠/替代形态可用；移动排版（字号阶梯、行宽、图片/动画降级）为设计 spec 必含项。
- 详细条款：见 shared/website6.0-impl-product-mobile-acceptance.md（M 系列条款，测试直接消费）。
- 影响优先级：Lighthouse 移动端 Perf≥90/A11y≥95 从"建议值"变为 CI/验收门禁（Q14 已采纳）。

## 3. MVP 定稿范围（实施基线）

**In（P0，M1-M3 交付）**：
1. 首页 `/`：佳瑞网/jary8 + 身份一句话 + 可变字体呼吸焦点，极简，移动优先
2. News `/news`：标题+简介+新窗口直跳（rel=noopener）、AI 标签筛选（完整模式）；构建期管线含降级模式
3. About `/about`：技能栈+履历时间线+简历内链；"问站长"本地 RAG 为 P1 不进 M2 门禁
4. Resume `/resume`：网页为主+打印 PDF；主导航无"简历"字样
5. 部署：Actions → Pages，`longzhengyun.github.io/website6.0` 路径验收；jary8.com 换绑为 M5 人工门禁
6. CI 红线：首屏 JS≤150KB、LCP<1.5s、CLS<0.05、axe 无严重违规、产物无密钥痕迹

**Out（本期不做，沿用 v1.0 §2 非目标清单）**：账号体系、自建后端/CMS、i18n、Lab 页（P1）、BYOK 默认开启、WebGPU 首页（二期候选）。

## 4. 里程碑产品口径

- M1/M2：以 §3 In 清单 1-4 + 6 为完成定义；LLM key 缺失不阻塞（降级模式即达 M2 验收态）。
- M3：key 注入后完整模式验证（AI 摘要+标签真实生成、失败回落上一版 news.json）。
- M4：测试出通过/未通过清单（含 M 系列移动条款）→ 站主知情确认后 M5 换绑 → M6 上线复验。
- 遗留观察项（不阻塞，随交付报告列出）：Actions schedule 延迟、Firefox 渐进增强范围、免费档政策变动。
